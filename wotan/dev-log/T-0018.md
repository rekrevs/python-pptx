# T-0018: Transparency/alpha API for fills and colors

**Status**: READY | **Size**: M
**Phase**: —

## Context
python-pptx has no API for color/fill transparency. The OOXML `a:alpha` and `a:alphaModFix` elements control opacity but are completely unexposed. `color.brightness` exists as a model, but alpha/transparency is missing. This is a frequently requested feature — upstream has an unmerged transparency PR (Sep 2025).

## Acceptance Criteria
- [ ] `color.alpha` property (read/write, float 0.0-1.0 where 1.0=opaque)
- [ ] Works with solid fills on shapes
- [ ] Works with font color
- [ ] OXML support for `a:alpha` element on color types (srgbClr, schemeClr)
- [ ] Unit tests for alpha get/set
- [ ] BDD acceptance test for transparency round-trip
