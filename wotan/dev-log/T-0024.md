# T-0024: Slide comments (read/write)

**Status**: DONE | **Size**: M

## Context
Slide comments stored in per-slide comment list and presentation-level author list parts, with no existing API.

## Acceptance Criteria
- [x] `slide.comments` returns a list of Comment objects
- [x] `comment.text` — comment text (read)
- [x] `comment.author` — author name (read)
- [x] `comment.timestamp` — creation time (read)
- [x] `slide.add_comment(text, author)` — create new comment
- [x] OXML classes for comment elements
- [x] Unit tests for comment access
- [x] BDD acceptance test for comments round-trip

## Implementation Notes

Two-part architecture: SlideCommentsPart (per-slide, RT.COMMENTS) + CommentAuthorsPart (package-level, RT.COMMENT_AUTHORS). Comment proxy class with text/author/timestamp. Lazy part creation on first add_comment(). 28 unit tests, 5 BDD scenarios.

All criteria met. 2867 unit tests, 1016 BDD scenarios pass.
