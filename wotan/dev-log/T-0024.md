# T-0024: Slide comments (read/write)

**Status**: READY | **Size**: M
**Phase**: —

## Context
Slide comments are stored in separate parts (`/ppt/comments/commentN.xml`) linked via relationships. The content type constants and relationship types exist in the OPC layer, but no part class, OXML classes, or Python API exists. Comments are preserved on round-trip via generic part handling.

## Acceptance Criteria
- [ ] `slide.comments` returns a CommentCollection
- [ ] `comment.text` — comment text (read/write)
- [ ] `comment.author` — author name (read)
- [ ] `comment.timestamp` — creation time (read)
- [ ] `slide.add_comment(text, author)` — create new comment
- [ ] OXML classes for comment elements (CT_Comment, CT_CommentList)
- [ ] SlideCommentsPart class
- [ ] Unit tests for comment CRUD
- [ ] BDD acceptance test for comments round-trip
