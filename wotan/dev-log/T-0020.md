# T-0020: Bullet and numbering formatting API

**Status**: READY | **Size**: M
**Phase**: —

## Context
Paragraph bullet/numbering OXML elements are already defined in `CT_TextParagraphProperties` (buChar, buAutoNum, buFont, buSzPts, buClr, buNone, etc.) but only `paragraph.level` is exposed as Python API. Users can't control bullet characters, numbering formats, bullet colors, or sizes without dropping to raw XML.

## Acceptance Criteria
- [ ] `paragraph.bullet` property returning a BulletFormat object
- [ ] `bullet.type` (none, char, auto_num, image) — read/write
- [ ] `bullet.char` — character bullet (read/write)
- [ ] `bullet.auto_num_type` — numbering format enum (read/write)
- [ ] `bullet.font` — bullet font name (read/write)
- [ ] `bullet.size` — bullet size in points or percentage (read/write)
- [ ] `bullet.color` — bullet color (read/write)
- [ ] Unit tests for all bullet properties
- [ ] BDD acceptance test for bullet formatting
