# T-0020: Bullet and numbering formatting API

**Status**: DONE | **Size**: M

## Context
Paragraph bullet/numbering OXML elements are already defined in `CT_TextParagraphProperties` tag sequence but only `paragraph.level` is exposed as Python API.

## Acceptance Criteria
- [x] `paragraph.bullet` property returning a BulletFormat object
- [x] `bullet.type` (none, char, auto_num) — read/write
- [x] `bullet.char` — character bullet (read/write)
- [x] `bullet.auto_num_type` — numbering format (read/write)
- [x] `bullet.font` — bullet font name (read/write)
- [x] `bullet.size` — bullet size in points (read/write)
- [x] `bullet.color` — bullet color (read/write via ColorFormat)
- [x] Unit tests for all bullet properties
- [x] BDD acceptance test for bullet formatting

## Implementation Notes

10 new OXML element classes, 6 ZeroOrOne declarations on CT_TextParagraphProperties, BulletFormat class in `src/pptx/text/bullet.py`. Bullet type elements are mutually exclusive (buNone/buAutoNum/buChar). Color reuses ColorFormat pattern. Size via buSzPts (hundredths of a point).

50 unit tests, 12 BDD scenarios.
