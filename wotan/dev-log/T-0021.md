# T-0021: Custom document properties

**Status**: READY | **Size**: M
**Phase**: —

## Context
Core properties (`prs.core_properties`) are fully implemented as a model to follow. Custom properties (`/docProps/custom.xml`) allow arbitrary key-value metadata on presentations but have no API. The XSD schema exists in `spec/`. This is useful for document management systems, templates, and AI-generated presentations that need to tag metadata.

## Acceptance Criteria
- [ ] `prs.custom_properties` returns a CustomProperties object
- [ ] Read existing custom properties (string, int, float, bool, datetime types)
- [ ] Add new custom properties with type inference
- [ ] Delete custom properties
- [ ] OXML element classes for custom properties part
- [ ] Unit tests for CRUD operations on custom properties
- [ ] BDD acceptance test for custom properties round-trip
