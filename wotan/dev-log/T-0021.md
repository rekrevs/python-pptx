# T-0021: Custom document properties

**Status**: DONE | **Size**: M

## Context
Core properties (`prs.core_properties`) are fully implemented as a model. Custom properties (`/docProps/custom.xml`) allow arbitrary key-value metadata but had no API.

## Acceptance Criteria
- [x] `prs.custom_properties` returns a CustomProperties dict-like object
- [x] Read existing custom properties (string, int, float, bool, datetime types)
- [x] Set custom properties with type inference
- [x] Delete custom properties
- [x] OXML element classes for custom properties part
- [x] Unit tests for CRUD operations on custom properties
- [x] BDD acceptance test for custom properties round-trip

## Implementation Notes

Dict-like interface on `CustomPropertiesPart` (`[]`, `del`, `in`, `len`, `iter`, `get`). Type inference on write (bool→int→float→datetime→str). New namespaces: `cust:` and `vt:`. Wired through Package → PresentationPart → Presentation.

29 unit tests, 4 BDD scenarios.
