# T-0017: Alt text API: shape.alt_text property (read/write)

**Status**: DONE | **Size**: M

## Context
The `cNvPr` element's `descr` attribute stores alt text for shapes. It's already used in picture creation templates but never exposed through the Python API. Adding `shape.alt_text` (getter/setter) on `BaseShape` is a high-value accessibility feature with low implementation effort.

Upstream has an unmerged PR for this (Dec 2025), confirming community demand.

## Acceptance Criteria
- [x] `shape.alt_text` getter returns `descr` attribute value (or empty string if absent)
- [x] `shape.alt_text` setter sets `descr` attribute on `cNvPr`
- [x] Works on all shape types (auto, picture, group, chart, table, connector)
- [x] Unit tests for getter/setter on multiple shape types
- [x] BDD acceptance test for alt text round-trip

## Approach
1. Add `descr = OptionalAttribute("descr", XsdString)` on `CT_NonVisualDrawingProps` in `src/pptx/oxml/shapes/shared.py`
2. Add `alt_text` property on `BaseShape` in `src/pptx/shapes/base.py` — follows same `_nvXxPr.cNvPr` pattern as `name`
3. Unit tests in `tests/shapes/test_base.py` — test get/set on shape element
4. OXML unit tests in `tests/oxml/shapes/test_shared.py` — test descr attribute
5. BDD feature in `features/shp-shared.feature`

### Design Decisions

**OptionalAttribute with default=None at OXML layer**: The `descr` attribute returns `None` when absent from XML, which is the truthful representation. The `alt_text` property on `BaseShape` translates `None` to `""` for the Python API, matching the acceptance criteria and providing a cleaner developer experience.

**Setter passes value directly to OXML**: Setting `alt_text` to a string sets the `descr` attribute. Setting to `None` (via the OXML layer) removes the attribute entirely.
