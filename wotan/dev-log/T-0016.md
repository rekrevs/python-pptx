# T-0016: Volume stock charts (VHLC/VOHLC)

**Status**: READY
**Phase**: —

## Context

Stock charts with volume (VHLC and VOHLC) are multi-plot charts that combine a bar chart for volume data with a stock chart for price data. These require a secondary axis and more complex XML structure than simple HLC/OHLC charts.

The enum values exist (`XL_CHART_TYPE.STOCK_VHLC`, `XL_CHART_TYPE.STOCK_VOHLC`) but are not registered in the `ChartXmlWriter` factory, so attempting to create them raises `NotImplementedError`.

## Implementation Notes

### Volume Stock Chart Types

| Enum | Series | Description |
|------|--------|-------------|
| `STOCK_VHLC` | 4 | Volume-High-Low-Close (bar + 3-series stock) |
| `STOCK_VOHLC` | 5 | Volume-Open-High-Low-Close (bar + 4-series stock) |

### Expected XML Structure (hypothesis)

```xml
<c:plotArea>
  <c:barChart>
    <c:ser><!-- Volume series --></c:ser>
    <c:axId val="..."/>  <!-- Category axis -->
    <c:axId val="..."/>  <!-- Secondary value axis -->
  </c:barChart>
  <c:stockChart>
    <c:ser><!-- High/Low/Close or O/H/L/C --></c:ser>
    <c:axId val="..."/>  <!-- Category axis (shared) -->
    <c:axId val="..."/>  <!-- Primary value axis -->
  </c:stockChart>
  <c:catAx>...</c:catAx>
  <c:valAx>...</c:valAx>      <!-- Primary (price) -->
  <c:valAx>...</c:valAx>      <!-- Secondary (volume) -->
</c:plotArea>
```
