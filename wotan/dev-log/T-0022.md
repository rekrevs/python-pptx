# T-0022: Theme access API (color scheme, font scheme)

**Status**: READY | **Size**: L
**Phase**: —

## Context
Themes control the visual identity of a presentation (colors, fonts, effects). The XML is preserved on round-trip but completely inaccessible from Python. `CT_OfficeStyleSheet` exists (30 lines) as a stub. A theme API would allow programmatic control over presentation styling — critical for template systems and AI-generated presentations.

## Acceptance Criteria
- [ ] `slide_master.theme` returns a Theme object
- [ ] `theme.color_scheme` with named color access (accent1-6, dark1-2, light1-2, hyperlink, followedHyperlink)
- [ ] Color scheme colors readable as RGBColor
- [ ] Color scheme colors writable
- [ ] `theme.font_scheme` with major/minor font access
- [ ] Font names readable and writable
- [ ] OXML classes for themeElements, clrScheme, fontScheme, fmtScheme
- [ ] Unit tests for theme read/write
- [ ] BDD acceptance test for theme modification
