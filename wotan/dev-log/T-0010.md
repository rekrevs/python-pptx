## Implementation Notes

### Stock Chart Types (in scope)

| Enum | Series | Description |
|------|--------|-------------|
| `STOCK_HLC` | 3 | High-Low-Close |
| `STOCK_OHLC` | 4 | Open-High-Low-Close |

### Key Implementation Details

- _StockChartXmlWriter at `src/pptx/chart/xmlwriter.py:1260`
- Uses `_CategorySeriesXmlWriter` for series data
- HLC: `<c:hiLowLines/>` only
- OHLC: `<c:hiLowLines/>` + `<c:upDownBars>`
- All series have `<c:marker><c:symbol val="none"/></c:marker>`

### Out of Scope (VHLC/VOHLC)

Volume variants (STOCK_VHLC, STOCK_VOHLC) require:
- Multi-plot structure (barChart + stockChart in plotArea)
- Secondary axis for volume
- Separate task for this complexity
